KAMILLA

Luxury Hair Extensions

A complete, custom online store — premium catalog, per-variant inventory, cart, Stripe checkout and a full admin panel. Built from scratch on Node.js with zero npm dependencies.

Open the store View the source

The store runs locally — start it with npm start (see below). This page is the project's presentation page.

The storefront

Everything a shop needs, nothing it doesn't.

A single Node process and one SQLite file. No build step, no framework, no dependency tree to maintain — just the product.

Catalog & search

Home, shop with category filters, search and sorting, plus rich product pages with variants and galleries.

Inventory-safe

Per-variant stock, low-stock alerts and atomic transactions so two buyers can never oversell the last unit.

Cart & checkout

A real shopping bag with Stripe Checkout (hosted, PCI-safe) and a local test mode for demos.

Admin panel

Dashboard with revenue and orders, full product/variant CRUD and order management — stock included.

Built for the world

Multi-currency, international shipping and Stripe for cards, Apple Pay and Google Pay.

Zero dependencies

Runs on Node built-ins only — node:sqlite, node:http, fetch, crypto. Nothing to install.

Get it running

Up and running in three commands.

Requires Node.js 22.5 or newer. No npm install — there are no packages.

Read the full guide 
git clone https://github.com/zmove-digital/kamilla
cd kamilla
cp .env.example .env
npm run seed      # demo catalog
npm start         # → http://localhost:3000
